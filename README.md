# ToDA 3 — пошаговая сетевая PvP-игра

Учебный проект на C++20 для двух игроков. Каждый управляет своим персонажем в окне raylib. Отдельный TCP-сервер ведёт лобби, проверяет действия и рассылает обоим клиентам состояние поля. На Windows можно сыграть на одном компьютере или на двух компьютерах в локальной сети.

## Сборка на Windows

Нужны PowerShell и 64-битный MinGW-w64 с `g++` и поддержкой C++20. Raylib и заголовок nlohmann/json входят в репозиторий. Открой PowerShell в корне проекта и собери сервер и графический клиент:

```powershell
g++ -std=c++20 -Ithird_party src/server/main.cpp src/server/net.cpp src/server/lobby.cpp src/server/game.cpp -o server.exe -lws2_32
g++ -std=c++20 -municode graphics/raylib_basic_window.cpp graphics/client_network.cpp src/client/client_state.cpp -Isrc -Isrc/utils -Ithird_party -Iraylib/include -o raylib_basic_window.exe raylib/lib/libraylibdll.a -lws2_32
```

Клиент использует DLL-версию raylib. Файл `raylib.dll` уже лежит в корне рядом с собранным клиентом.

## Запуск матча

1. В первом PowerShell выполни `.\server.exe`. Оставь терминал открытым. Для остановки сервера нажми **Ctrl+C**.
2. Во втором PowerShell из корня проекта запусти два отдельных окна игроков:

   ```powershell
   Start-Process .\raylib_basic_window.exe -ArgumentList Player1
   Start-Process .\raylib_basic_window.exe -ArgumentList Player2
   ```

   Имена можно заменить своими. При запуске без аргумента клиент предложит ввести ник в окне и подтвердить его клавишей **Enter**.
3. Нажми **R** в каждом окне. Когда оба игрока готовы, появится поле 5×5. Метка `[YOU]` отмечает твоего персонажа, а `[TURN]` показывает, чей сейчас ход.

### На двух компьютерах в локальной сети

1. На компьютере хоста запусти `.\server.exe`, затем в другом терминале — `.\raylib_basic_window.exe Player1`. Без второго аргумента клиент подключается к `127.0.0.1`.
2. На хосте выполни `ipconfig` и найди IPv4-адрес активного Wi-Fi или Ethernet. Если брандмауэр Windows запросит разрешение для сервера, разреши доступ в частной сети. Сервер принимает TCP-подключения на порту `2024`.
3. На втором компьютере запусти клиент, указав после ника IPv4-адрес хоста. Например:

   ```powershell
   .\raylib_basic_window.exe Никита 192.168.1.34
   ```

   Замени адрес из примера адресом хоста. Когда в обоих окнах появятся ники игроков, каждый нажимает **R**.

## Как играть

У каждого персонажа 10 HP. Красный начинает в левом верхнем углу и ходит первым, синий начинает в правом нижнем. За ход можно один раз переместиться и один раз атаковать в любом порядке.

| Управление | Действие |
| --- | --- |
| ЛКМ по свободной соседней клетке | Переместиться на одну клетку по горизонтали или вертикали. |
| ПКМ по клетке соперника | Нанести 1 урон, если соперник стоит на соседней клетке по горизонтали или вертикали. |
| **T** | Завершить ход, даже если остались действия. |
| **R** в лобби | Подтвердить готовность к первому или следующему матчу. |

Когда HP одного игрока падает до нуля, оба окна показывают результат и возвращаются в лобби. Для реванша оба снова нажимают **R**. Если соперник закроет окно во время боя, матч прервётся, а оставшийся игрок вернётся в лобби.

## Как связаны клиент и сервер

Например, при щелчке по клетке справа от стартовой позиции красного клиент отправляет строку `MOVE 1 0` с переводом строки. Сервер проверяет очередь и допустимость шага. При успехе он отвечает отправителю `OK MOVE` и отправляет обоим игрокам `GAME_STATE` с новыми координатами. По этому сообщению оба окна перерисовывают поле. Ники и готовность приходят отдельно в `LOBBY_STATE`. [Полное описание протокола](docs/protocol.md)

| Каталог | Содержимое |
| --- | --- |
| [src/server](src/server) | TCP-сервер на Winsock, лобби и правила боя. |
| [graphics](graphics) | Окно raylib, ввод с мыши и клавиатуры, сетевое подключение графического клиента под Windows. |
| [src/client](src/client) | Консольный клиент для macOS/Linux и разбор сообщений сервера, который использует также графический клиент. |
| [src/common](src/common) | Структуры для состояния лобби, поля и игроков на клиенте. |

## Проверка сервера

Запусти сервер и закрой игровые окна, чтобы освободить оба места в лобби. Из корня проекта во втором PowerShell выполни тесты по очереди. Каждый скрипт подключает двух игроков к локальному серверу и проверяет ответы по TCP.

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\tests\end-turn.ps1
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\tests\attack.ps1
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\tests\game-over.ps1
```

Тесты проверяют передачу хода и восстановление действий, урон и ограничения атаки, завершение матча и повторную игру на тех же подключениях. Успешный скрипт выводит строку с `tests passed`.

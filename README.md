# ТЗ проекта
## Описание игрового процесса
### Жанр: пошаговая тактическая сетевая PvP-игра
### Лобби. Игрок покупает и выбирает персонажей, прокачивает их атрибуты — сила / ловкость / интеллект (эта прокачка перманентная, живёт между матчами). По кнопке "Найти матч" запускается поиск соперника по рейтингу — чем ближе и выше рейтинг оппонента, тем больше дадут за победу.
Бой Игроки ходят по очереди на клетчатом поле. За ход — ограниченное число действий (движение + атака/заклинание). На поле есть клетки с бонусами (баффы, лечение) и препятствия. У персонажа есть оружие (ближний/дальний бой) и 1–2 заклинания с кулдауном по ходам. Внутри самого боя — отдельная, временная прокачка/усиления — например, подбираемые баффы, которые действуют только до конца матча.
Смерть персонажа может означать не моментальное поражение — рассматриваем систему ограниченных воскрешений (с задержкой/штрафом), чтобы бой не заканчивался слишком быстро.
Помимо классического 1 на 1 рассматриваем и другие режимы боя — команда на команду, либо free-for-all, где несколько игроков дерутся каждый сам за себя. Сделаем если хватит сил.
### Итог матча: Победитель определяется по факту гибели/лимита воскрешений соперника (или команды/соперников в случае других режимов) или по очкам, если упёрлись в лимит ходов. Рейтинг пересчитывается по формуле вида ELO.
